## 2️⃣ Download the Setup

<p align="center">
  <strong>Download the ready-made configuration.</strong>
  <br>
  <sub>You will import this file in Step 4.</sub>
</p>

<br>

<p align="center">
  <a href="https://github.com/oxanuragofficial/nighttab-setup-guide-final2/releases/latest/download/nighttab-backup.json">
    <img src="https://img.shields.io/badge/⬇️%20DOWNLOAD%20SETUP-nighttab--backup.json-2563eb?style=for-the-badge" alt="Download Browser Setup">
  </a>
</p>

<br>

<p align="center">
</p> <p align="center"> <sub>Keep this file. You will need it during import.</sub> </p> <br>
3️⃣ Open Settings

Open a new browser tab.

Then open the Settings ⚙️ button.

<p align="center"> <img src="docs/images/01-new-tab-settings.png" alt="Open Settings in the new tab" width="800" > </p> <p align="center"> <sub>Open the Settings button highlighted in the image.</sub> </p> <br>
4️⃣ Import the Setup

Inside Settings, open:

<p align="center">
Data → Restore
</p> <p align="center"> <img src="docs/images/02-data-restore.png" alt="Open Data and Restore" width="800" > </p> <br>

Click Import from file.

<p align="center"> <img src="docs/images/03-import-file.png" alt="Import from file" width="700" > </p> <br>

Select:

<p align="center">
nighttab-backup.json
</p> <br>
🎉 Done

Return to your new-tab page.

Your ready-made browser setup should now be restored.
